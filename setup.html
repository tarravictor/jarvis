J.A.R.V.I.S. / MUSIC CONNECTION

Connect YouTube Music

Jarvis can speak back and control the song playing in another browser tab. Install the included music extension once to connect those tabs.

  1. Open Jarvis in Chrome, Edge, or Brave. Use the same browser for YouTube Music. The Codex in-app browser cannot load this extension.
  2. Open your browser's extensions page: chrome://extensions, edge://extensions, or brave://extensions.
  3. Switch on Developer mode, click Load unpacked, and select the extension folder inside jarvis-assistant.
  4. If Jarvis is open from a file address (file://), open the extension's Details and switch on Allow access to file URLs. You can instead use a localhost address as described in the README.
  5. Open YouTube Music and start a song once. Reload Jarvis, then click CHECK LINK.
Try: “Hey Jarvis, pause,” “Hey Jarvis, play,” or “Hey Jarvis, skip.” Click TEST VOICE on the Jarvis page to hear a spoken sample.

If it does not connect

Make sure both tabs are in the browser with the extension. If Jarvis shows OPEN YOUTUBE MUSIC, open that tab. If it shows CHOOSE A SONG, start playback there. If it shows EXTENSION NOT CONNECTED, reload Jarvis and check the extension's file access switch when using a file address.
